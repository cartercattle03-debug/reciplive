# Decisions

- 2026-10-14: RecipLive built from Savannah 2.0 as its own app (separate from HerdLive for now; may join it later). Same stack and look as HerdLive.
- 2026-10-14: Customer logins - an owner (e.g. Lehman) gets a read-only view of only their cows and report.
- 2026-10-14: Sheet2 and Sort Sheet were scratch tabs - not brought over.
- 2026-10-14: Customer PDF = Print / Save as PDF from Customer Search for now; emailing it from the app is for later.
- 2026-10-14: Helper columns are not stored - all worked out live (src/lib/recip.ts), checked row-for-row against the workbook.
- 2026-10-14: Attempt # = her records in batch order, then entry order (the sheet's formula had a fixed "row 2" in it).
- 2026-10-14: "Confirm Delivery Updates" (in How To Use but never written) isn't needed - delivery saves as it's picked.
- 2026-10-14: Add transfers is a 10-line grid (+10 more lines, paste a column to fill down, one Add for all) - batches run 40-100+ transfers.
- 2026-10-14: Manager login = view only: sees every page, no changes, no import, no print/download buttons. Only the owner saves.
- 2026-10-14: Red ✕ to delete beside every Transfers line (asks first, Undo keeps a copy); red ✕ clears a line on the Add transfers grid.
- 2026-10-14: Open Inventory gets a Cull tick box (Cull checked = her record turns Culled, dated) and an Edit pop-up for her latest record.
- 2026-10-14: Master Archive: each cow's purchase, every transfer / Pass, every preg check, delivery, cull and sale in order - built live from the records (new CowEvent table holds cull dates). Also at the bottom of Cow Lookup.
- 2026-10-14: Year box at the top; a new year (2027) starts a fresh slate on Dashboard, Transfers, 75+ Day, Breakdowns, Customer Search and Open Inventory.
- 2026-10-14: Open Inventory by year: add new cows, tick to Cull or Move to next year's opens, red X takes a gone cow off the list. A Nov/Dec transfer checked Open in Jan/Feb falls to the new year's opens.
- 2026-10-14: Preg Check columns: Group, Cow ID, Days Bred, Result, Check Date, Status, Due Date, Notes (Mating / Owner show when pointing at the Cow ID).
- 2026-10-14: Each preg check result gets its own Check Date - today when picked, cleared if the result is taken back off. The page-wide Date box is gone.
- 2026-10-14: A transfer typed as 54 / 968h goes on the cow already on file as 054 / 968H (only when exactly one fits), so it takes her off the open list.
- 2026-10-14: Preg Check: Mating column (editable) after Status; Due Date editable (typed date wins, Days Bred follows; blank goes back to transfer + 276); + Add cow puts a missed cow on the sheet as a Pending transfer so she counts in the totals.
- 2026-10-14: RecipLive colors: sky blue #0369a1 headings, copper #b8732e accent, dark headings (to read apart from HerdLive's navy / rust).
- 2026-10-14: Table rows: light gray every other row + thin charcoal line under each row (look D).
- 2026-10-14: Page tabs on a solid blue bar, white bold text; the open page is a white tab with a copper line.
- 2026-10-14: Cow IDs black on every page; the Group column is the blue one.
- 2026-10-14: Preg Check: Status next to Result; only the Result column is cream-shaded (others still click to edit); Notes twice as wide (also on Transfers and Open Inventory).
- 2026-10-14: Preg Check Result is three tap buttons (Probable / Safe / Open; tap again to clear) - built for the iPad at the chute.
- 2026-10-14: Preg Check: no column shading; Result buttons in their own colors (yellow / bright green / bright red); Safe and Open text brighter everywhere.
- 2026-10-14: Customer portal gets their own breakdowns (by Group, Embryo Type, Company, Grade, with the grids) and a Year box; owner-only 'View as <owner>' (/my?as=) shows exactly what a customer sees.
- 2026-10-14: Culled cows count in the pregnancy rate: as Open (Safe if confirmed Safe before the cull; a culled Pass stays a Pass). Overall rate on the workbook data: 48.2% the sheet's way -> 41.8%.
- 2026-10-14: A culled cow counts Open even if checked Safe first (6019) - a failed pregnancy. Only a culled Pass (stays Pass) or a cow already Delivered (stays Safe) differ.
- 2026-10-14: Breakdown and Dashboard tables show a Culled column (counted against Open) and Pregnant / Checked (e.g. 1/3) beside the rate, so the math is on screen.
- 2026-10-14: Billing for confirmed 75-day pregnancies: Ready to bill (Safe records not on an open invoice; culled never), Build invoices (one per owner, one price from settings), price changeable for every line or one line, adjustment lines (minus = discount), void keeps the number and frees the cows, QuickBooks Online CSV import file per invoice or all not yet exported. Billed cows are matched by record and by cow + group + mating, so a re-import can't bill twice.
